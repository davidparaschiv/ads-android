# Firebase Android

Descarcă fișierul `google-services.json` din consola Firebase pentru aplicația cu package ID `ro.rezerva.app` și pune-l în acest director:

`android/app/google-services.json`

Nu redenumi fișierul și nu îl salva în `src/main`. După adăugare rulează din rădăcina proiectului:

```bash
npm run android:sync
```
